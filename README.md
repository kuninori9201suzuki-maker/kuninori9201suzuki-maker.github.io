## 3. デザイン方針

目標サイト（kato-rashi.co.jp）は「設備と技術（モノ）」を売るサイト、丸忍工業所は「人手と受け入れ体制（コト）」を売る会社です。**質感は目標に寄せ、構成は御社用に組み替えています。**

| 要素 | 方針 | 理由 |
|---|---|---|
| 配色 | 白基調＋濃紺（#0d2440）＋朱のアクセント（#e8622c） | 濃紺で製造業の信用を、朱で「人の手・熱」を表す |
| 構造 | 1枚もの・縦一本 | 迷わせない。発注担当者が判断する順に並べる |
| 訴求 | 数字ではなく「構造」で語る | 人数・面積を出さない方針のため（第5章参照） |
| 写真 | 引きの構図を主役に | 「人が集まって手を動かしている」画がそのまま説得力になる |
| 英語併記 | 見出しに小さく配置 | 目標サイトの質感を再現。多言語ページは作らない |
| 動き | フェードイン、現在位置のメニュー表示のみ | 過剰な演出は信用を下げる |
| 更新機能 | なし（静的HTML） | 保守負担ゼロ。乗っ取りリスクもゼロ |

外部ライブラリ・Webフォント・CDNを一切使っていないため、**表示が速く、将来壊れません。**

## 5. 注意していただきたい2点

### ① 数字を出さない分、写真の重要度が上がりました
人数・面積・日数をすべて外したため、**「本当に人手があるのか」を裏づけるものが写真だけになりました。**
とくに **`hero.svg`（作業する人が10名以上写る引き）** と **`company-team.svg`（朝礼など人数が見えるカット）** の2枚が、このサイトの説得力をほぼ単独で支えています。この2枚は妥協せずに撮ってください。

### ② 返信時間の約束を削除しました
「当日中にご返信します」は全て削除し、代わりに「**内容を確認のうえ、担当者よりご連絡いたします**」という表現にしています。約束していないので破ることもありません。

ただし、**返信の速さは外注先選びで実際に効きます。**「2営業日以内」「3営業日以内」など、**確実に守れる範囲**であれば書いた方が有利です。守れる日数が決まりましたらお知らせください。該当箇所に追記します。

## 7. 撮影リスト（12カット）

`assets/img/` の仮画像には、それぞれ「撮るべきカット」が書いてあります。同じファイル名で写真を上書きすれば差し替わります（`.svg` を `.jpg` に変える場合は、`index.html` 内のファイル名も修正が必要です）。

| ファイル | 撮るもの | 優先度 |
|---|---|---|
| `hero.svg` | **工場全景／作業する人が10名以上写る引き** | ★最重要 |
| `company-team.svg` | **朝礼など人数が見えるカット** | ★最重要 |
| `strength-hands.svg` | 手元のアップ（組付作業中） | 高 |
| `strength-line.svg` | 作業台に人が並ぶ引きの構図 | 高 |
| `strength-check.svg` | 検査・目視チェックの様子 | 高 |
| `service-01/02/03.svg` | 自動車部品／介護ベッド／清掃用具の作業 | 中 |
| `factory-kanaori/shimoe.svg` | 各工場の外観（金折・下江） | 中 |
| `company-office.svg` | 社長・工場長の人物カット | 中 |
| `cta-bg.svg` | 工場内の広い引き（中央は空けて撮影） | 低 |

### 撮影時の注意（スマホ撮影の場合）
1. **昼間、シャッターや窓を全開にして撮る**（暗さが失敗の9割）
2. **必ず横向き（横長）で撮る**（縦写真は使えません）
3. **引きの構図を最優先**（人数が伝わることが最重要）
4. **人はカメラを見ない、作業中を撮る**（集合写真は求人の顔になり逆効果）
5. **同じ場所で10枚以上撮る**（選べる状態にする）
6. **部品が写り込んでも消さずに残す**（トリミングで使える場合があります）

## 8. 公開までの手順

### STEP 1／お問い合わせフォームの設定（必須）
静的サイトのため、フォーム送信には外部サービスが必要です。**設定するまでフォームは動きません。**

推奨は [Formspree](https://formspree.io/)（無料枠あり・設定5分）。
1. アカウントを作成し、送信先メールに `info@marunin.co.jp` などを登録
2. 発行されたフォームIDを控える
3. `index.html` 内の `<form ... action="#"` を `action="https://formspree.io/f/【フォームID】"` に書き換える
4. **必ずテスト送信し、受信を確認する**

`index.html` の該当箇所には、同じ手順をコメントで書いてあります。

### STEP 2／ドメインの設定
**`marunin.co.jp` は既に御社名義で登録済みです（登録2011年／有効期限2027年1月31日）。新規取得は不要です。**

現在はメール（MXレコード）だけが設定され、Webは未設定の状態です。ホスティング先を決めたうえで、**Aレコードを追加するだけ**で公開できます。

- ネームサーバーは `ns.technowave.ne.jp`（テクノウェーブ社）
- **MXレコードには絶対に触れないでください。** 触ると `@marunin.co.jp` のメールが止まります
- 作業はテクノウェーブ社の管理画面、または同社の担当者へ依頼

### STEP 3／ホスティング
静的サイトなので、無料〜月数百円で公開できます。
- **Netlify / Cloudflare Pages**：無料。フォルダをドラッグ&ドロップするだけ
- **既存のレンタルサーバー**：FTPでファイル一式をアップロード

### STEP 4／公開前チェック
- [ ] `draft-bar` の行を削除した
- [ ] 仮データ（第6章の一覧）をすべて実データに差し替えた
